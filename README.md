# Pulveriza Safra

Aplicativo para controle de aplicações agrícolas.

Funcionalidades previstas:
- cadastro de culturas;
- cadastro de talhões;
- cadastro de produtos e estoque;
- registro de aplicações;
- controle de dosagem;
- registro de clima;
- alerta de reaplicação;
- alerta de carência;
- custo por hectare;
- histórico por cultura, talhão e produto.
